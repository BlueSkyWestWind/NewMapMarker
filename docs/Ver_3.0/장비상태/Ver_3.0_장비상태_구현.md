# Ver 3.0 장비 시설 상태 구현

근거: `Ver_3.0_계획.md` 3장(장비 시설 상태), 8장의 "구현 문서 작성 전 확인할 제안".
범위: 상태 판정·표시색·상태 필터·연도 필터 보정·마커 색상 5개 추가. DB 변경은 없다.

## 데이터

`EquipmentMarker`에 두 값을 더한다. 둘 다 `fetchMapMarkers`가 조회 직후 계산해 채운다(저장하지 않는다).

| 필드 | 뜻 |
|---|---|
| `facilityRecords` | 이 마커 자신의 `information` 행 전부의 `{ year, installDate, openDate }`. 지금은 첫 행만 읽는다 |
| `groupYears` | 연도 필터용. 자기 + 숨은 SUB의 장비 연도 집합. 비면 `미지정` |
| `facilityStatus` | `미시설` · `시설` · `개통완료` · `올해 대상 없음` |

기준 연도는 `computeFacilityStatuses(markers, year)`의 인자다. 호출부가 `new Date().getFullYear()`를 넘기므로 연도별 판정으로 넓힐 때 이 호출만 바꾼다.

## 판정 (`lib/facility-status.ts`, 순수함수)

대상 장비 = 기준 연도(`year === 기준 연도`)인 `facilityRecords`. 대표 마커는 자기 + **숨은 SUB**(`parentMarkerId`가 자기이고 `detachedVisible`이 아님)의 대상 장비를 합친다. 개별 표시 SUB는 자기 장비만 쓴다.

1. 대상 장비가 없다 → `올해 대상 없음`
2. 시설일이 빈 장비가 하나라도 있다 → `미시설` (시설일 없이 개통일만 있는 예외도 여기)
3. 개통일이 빈 장비가 하나라도 있다 → `시설`
4. 그 외 → `개통완료`

SUB 마커 자신의 상태는 대표가 합산해 쓰므로 의미가 없다. 숨은 SUB에는 자기 장비 기준으로 계산해 둔다(표시되지 않는다).

## 표시색 (`lib/marker-svg.ts`)

`getEffectiveMarkerColor`가 `mode === "equipment"`이고 임시·대기 마커가 아니면 상태색을 돌려준다.

| 상태 | 색 |
|---|---|
| 미시설 | `#10b981` |
| 시설 | `#64748b` |
| 개통완료 | `#ffffff` |
| 올해 대상 없음 | 저장된 `marker.color` |

지도·색상 필터·클러스터·캡처가 이 함수 하나를 거치므로 표시색이 일치한다. DB의 `color`는 바꾸지 않는다.
흰 핀은 흰 테두리·흰 안쪽 점이 배경에 묻히므로 `#ffffff`일 때만 어두운 테두리(`#475569`)와 안쪽 점을 쓴다.

## 필터

- `MarkerFilterState.selectedStatuses`를 더한다. 옵션은 고정 순서 `미시설`·`시설`·`개통완료`·`올해 대상 없음`(그 상태의 마커가 있는 것만).
- 기본 선택은 `미시설`·`시설`. 모두 선택하면 버튼에 `전체`.
- 빈 집합은 "걸러내지 않음"이다(기존 연도·색상 필터와 같은 규칙).
- 상태·연도·색상·사업구분·태그는 각각 독립이다. 서로의 선택을 덮어쓰지 않는다.
- **빈 집합 주의:** 기본값으로 고를 값이 하나도 없으면(예: 미시설·시설 국소가 전혀 없음) 선택이 빈 집합이 되고, 빈 집합은 걸러내지 않으므로 그 차원은 전체가 보인다. 처음 화면을 억지로 비우려면 "선택 안 함"을 구분하는 별도 표현이 필요해 이번에는 하지 않았다.
- 연도 필터는 `groupYears` 중 하나라도 선택되면 통과한다.
- `defaultSelectedYears`의 "올해 마커가 없으면 전체 선택" 폴백을 지운다. 올해와 `미지정`만 고른다.
- 스토어의 `toggleFilterValue`·`selectAllFilterValues` 타입에 `status`를 더한다. 필터 요약 건수(`getMarkerVisibilityStats`)도 같은 판정을 쓴다.

## 마커 색상 5개

`marker-edit-modal.tsx`의 `COLOR_OPTIONS`와 `facility-teams.ts`의 `LEGACY_COLOR_NAMES`·`COLOR_NAME_ALIASES`·`COLOR_FILTER_ORDER`에 더한다. 백업·복원에서 이름이 유지되도록 두 표를 함께 고친다.

네이비 `#1e3a8a` · 스카이 `#38bdf8` · 옐로 `#facc15` · 브라운 `#92400e` · 버건디 `#9f1239`.
색상 필터 라벨용으로 `#ffffff` → `흰색`도 더한다.

## 건드리지 않는 것

- 저장 색상, 백업 파일 형식, 위치등록 업로드.
- 축전지·위치·대시보드 모드(상태색은 장비 모드 전용).
- 같은 hex를 쓰는 저장 색상과 상태색의 구분(계획서 3장 "색상 겹침": 상태 필터로 구분).
