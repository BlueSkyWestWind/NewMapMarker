# 작업 명세서 — 날씨 타임라인 표 열 폭 재배분 (강수 열 겹침 수정)

## 배경

대시보드/작업 안전 날씨의 시간대별 표(`WeatherTimelineTable`)에서 강수 확률+강수량이
길어지면(예: "60% 7.0mm") 강수 열이 좁아 옆의 판정 열과 겹쳐 보인다. 반대로 시각·기온/체감·
습도 열은 실제 내용보다 폭이 넓어 빈 공간이 남는다. 사용자가 스크린샷으로 확인.

## 요구사항

`src/features/worksite-weather/components/weather-timeline-table.tsx`의 `colgroup`
(37~47번째 줄 근처) 퍼센트 폭만 재배분한다. 셀 내용·마크업·로직은 그대로 둔다.

현재:
```
시각 11% / 기온·체감 35% / 습도 14% / 바람 18% / 강수 12% / 판정 10%  (합 100%)
```

변경 후:
```
시각 9% / 기온·체감 27% / 습도 11% / 바람 19% / 강수 24% / 판정 10%  (합 100%)
```

- 시각·기온/체감·습도 열은 좁히고, 강수 열은 크게 넓힌다(12%→24%). 바람 열은 소폭(18%→19%) 넓힌다.
  판정 열(10%)은 그대로 둔다.
- 합계가 정확히 100%가 되게 한다.

  이 조건이 깨지지 않는지 확인만 한다. `whitespace-nowrap`은 그대로 둔다.
