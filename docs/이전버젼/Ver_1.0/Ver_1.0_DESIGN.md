# Ver_1.0 디자인 명세 (Design System & UI Spec)

- 제품: **MapMarker Pro** (`0004_NewMapMarker`)
- 문서 버전: **Ver_1.0**
- 작성일: 2026-07-25
- 관련 문서: [PLAN](./Ver_1.0_PLAN.md) · [PRD](./Ver_1.0_PRD.md) · [IA](./Ver_1.0_IA.md) · [USECASE](./Ver_1.0_USECASE.md)

## 1. 디자인 원칙

| # | 원칙 | 적용 |
| --- | --- | --- |
| 1 | **지도가 주인공** | UI 크롬은 어둡고 낮은 채도로 물러나고, 지도와 마커 색만 채도를 갖는다 |
| 2 | **한 화면 완결** | 사이드바 + 지도의 2열 고정. 페이지 이동 없이 조회·편집·캡처가 끝난다 |
| 3 | **표는 자르지 않는다** | 셀 줄바꿈 금지 · 가로 스크롤 금지. 폭이 부족하면 **박스/모달 폭을 키운다** |
| 4 | **글로우로 엘리베이션** | 어두운 배경에서 그림자는 보이지 않는다. 브랜드 글로우로 활성·포커스를 표현 |
| 5 | **상태는 문구로 말한다** | 건수·진행률·실패 목록을 숫자와 문장으로 명시(빈 원형 스피너로 끝내지 않음) |
| 6 | **한국어 우선** | UI 문구·주석·오류 메시지 모두 한국어 |

### 시각적 레퍼런스

"neon control room" 계열의 관제 콘솔 룩 — 중립 차콜 배경 + 단일 브랜드 블루 강조.

## 2. 컬러 시스템

### 2.1 브랜드 리스킨 램프

앱 전역이 `bg-slate-*` · `text-indigo-*` 유틸을 직접 사용하므로, **이 두 램프만 덮어써도 전 화면이 리스킨**된다.
(`tailwind.config.ts`의 deep-merge를 이용한 부분 지정)

**slate — 푸른끼 제거한 중립 차콜**

| 200 | `#e2e2e8` | 보조 텍스트 |
| 300 | `#c9c9d2` | 비활성 텍스트 |

## 3. 타이포그래피

| 역할 | 클래스 | 크기 | 굵기 |
| --- | --- | --- | --- |
| 앱 타이틀 | `text-lg font-bold leading-tight` | 18px | 700 |
| 섹션 헤더(아코디언) | `text-xs font-semibold` | 12px | 600 |
| 본문 | `text-sm` | 14px | 400 |
| 보조/메타 | `text-[11px]` | 11px | 400~500 |
| 캡션·건수 요약 | `text-[10px] text-slate-500` | 10px | 400 |
| 모드 탭 | `text-[11px] font-semibold` | 11px | 600 |

- 사이드바는 정보 밀도가 높아 **10~12px 구간을 적극 사용**한다.
- 건수 요약처럼 넘칠 수 있는 한 줄 텍스트는 `overflow-hidden text-ellipsis whitespace-nowrap` + `title` 속성으로 전문을 툴팁 제공한다.

## 5. 엘리베이션 — 글로우

어두운 UI에서 그림자는 인지되지 않으므로 **브랜드 글로우**로 층위를 표현한다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `shadow-glow` | `0 0 0 1px #3a4cd1, 0 0 18px -2px rgba(58,76,209,.45)` | 활성 탭, 선택된 마커 항목, 열린 패널 |
| `shadow-glow-sm` | `0 0 14px -4px rgba(58,76,209,.5)` | hover, 포커스, 플로팅 버튼 |

배경 층위는 명도로 구분한다: `slate-950`(앱) → `slate-900/95`(사이드바) → `slate-800`(카드) → `black/20`(탭 트랙).

## 6. 모션

| 대상 | 사양 |
| --- | --- |
| 아코디언 열기 | `accordion-down` 0.2s ease-out (`--radix-accordion-content-height`) |
| 아코디언 닫기 | `accordion-up` 0.2s ease-out |
| 색상 전환 | `transition-colors` (기본 150ms) |
| 모달 | Radix Dialog 기본 페이드/스케일 |
| 프레임 애니메이션 | `framer-motion` — 필요한 곳에 한정 사용 |

원칙: **지도 조작을 지연시키는 애니메이션은 넣지 않는다.** 200ms를 넘기지 않는다.

### 7.2 반응형 정책

Ver_1.0은 **데스크톱 전용**이다. 좁은 화면에서는 사이드바를 접어 지도 폭을 확보한다.
모바일 전용 레이아웃은 범위 외([PRD §9](./Ver_1.0_PRD.md)).

## 8. 컴포넌트 스펙

### 8.1 모드 탭 (`ModeTabs`)

```
컨테이너  mt-4 flex rounded-lg border border-slate-700/60 bg-black/20 p-1
아이템    flex-1 rounded-md px-1.5 py-2 gap-1 text-[11px] font-semibold
          아이콘 + 라벨 가로 배치, transition-colors
```

| 상태 | 표현 |
| --- | --- |
| 활성 | 밝은 배경 + 브랜드 글로우, 텍스트 `slate-50` |
| 기본 | 투명 배경, 텍스트 `slate-400` |
| 잠김 | `disabled` + `Lock` 아이콘, `title="로그인 후 이용할 수 있습니다"` |

아이콘: 장비 `Server` · 축전지 `Battery` · 위치 `MapPin`

### 8.2 사이드바 헤더

- 좌: `MapPin`(에메랄드 `text-emerald-400`) + "MapMarker **Pro**"(Pro는 `text-indigo-400`)
- 하단 캡션: 건수 요약 — `장비 1,204건 · 로딩 중 · 좌표 없음 3건` 형태로 `·` 연결, 빈 항목은 생략
- 우: `AuthHeader` + 접기 버튼(`h-7 w-7 text-slate-400`)

### 8.3 GPSMAP 링크 배너

```
h-8 rounded-md border border-indigo-500/40 bg-indigo-600/15
text-[11px] font-medium text-indigo-200  hover:bg-indigo-600/25
아이콘 Waypoints(3.5) + "주소/좌표 통합 변환기"
```
로그인 시에만 렌더한다.

### 8.4 아코디언 섹션

- `Accordion type="multiple"` — 여러 섹션 동시 개방 허용
- 기본 펼침: 일반 모드 `["markers"]` / 위치 모드 `["location-address","location-excel","markers"]`
- 트리거: `py-2 text-xs font-semibold hover:no-underline` + 좌측 3.5 아이콘
- 섹션 아이콘: 마커목록 `MapPin` · 필터 `Filter` · 검색 `Search` · 엑셀 `FileSpreadsheet` · 백업 `Database` · 변환기 `Waypoints`

### 8.5 위치 모드 안내 배너

```
rounded-lg border border-emerald-800/50 bg-emerald-950/40
px-3 py-2 text-[11px] leading-relaxed text-emerald-200/90
```
문구: "엑셀 업로드로 위치를 등록하세요. 이름·주소만 표시하며, 새로고침 시 사라집니다. 우측 카메라로 영역 캡처할 수 있습니다."

> 임시 데이터임을 **에메랄드 계열**로 구분해, 영구 저장되는 장비/축전지와 색으로 구별한다.

### 8.6 플로팅 컨트롤

우측 세로 스택. 모든 버튼에 `title` 툴팁 필수.

| 순서 | 기능 | 툴팁 |
| --- | --- | --- |
| 1 | 영역 캡처 | `영역 격자 자동 캡처` |
| 2 | 내 위치 | `내 위치` |
| 3 | 지적편집도 | `지적편집도` |
| 4 | 클러스터 토글 | `클러스터` |
| 5 | 클러스터 아이콘 | 현재 스타일에 따라 동적 |
| 6 | 확대 | `확대 (1단계)` |
| 7 | 줌 슬라이더 | `드래그하여 확대/축소 (1레벨 단위)` · `aria-label="지도 확대 축소"` |
| 8 | 레벨 표시 | `현재 줌 레벨 N (작을수록 확대)` |
| 9 | 축소 | `축소 (1단계)` |
| 10 | 기준점 복귀 | `광주 시청` |

토글류는 **활성 시 브랜드 글로우**로 on 상태를 표시한다.

### 8.7 마커 (SVG)

| 요소 | 규칙 |
| --- | --- |
| 형태 | 핀 형태 SVG, `marker-svg.ts`에서 생성 |
| 채움 | 시설팀 색 / 상태 색 |
| 외곽선 | 어두운 지도·위성 양쪽에서 판독되도록 대비 스트로크 유지 |
| 선택 | 브랜드 글로우 + 확대 |
| 대표/SUB | 지도에는 **대표 1핀만**. `detached_visible`인 SUB만 추가 렌더 |
| 겹침 | 분리 직후 새 대표는 원 대표와 같은 좌표 → **드래그 안내 토스트**로 해소 유도 |

### 8.8 클러스터 아이콘

| 스타일 | 표현 |
| --- | --- |
| **파이** | 채워진 원을 팀 색 비율로 분할 |
| **도넛** (기본) | 가운데가 비어 총 건수 숫자를 표시 |

- 세그먼트 색은 §2.3 시설팀 색을 그대로 사용해 지도 마커와 색 언어를 통일한다.
- 선택 상태는 persist된다.

### 8.9 정보창 오버레이

- 마커 상단에 부착, **드래그로 자유 이동** 가능(겹침 수동 해소)
- 캡처 모드(`isInfoWindowCaptureMode`)에서는 마커에서 떨어뜨려 자동 배치 → 라벨 가림 방지
- 배경 `slate-900` 계열 + 얇은 보더, 텍스트 11~12px

### 8.10 모달

| 항목 | 규칙 |
| --- | --- |
| 기반 | Radix Dialog (shadcn `dialog`) |
| 폭 | **내용에 맞춰 확장.** 표가 잘리면 모달 폭을 키운다 |
| 스크롤 | **세로만.** 가로 스크롤 금지 |
| 본문 | 섹션 구분선(`slate-800`)으로 그룹 분리 |
| 액션 | 우하단 정렬, 파괴적 동작은 `destructive` 변형 |
| 지연 로드 | 상세·편집 모달은 `next/dynamic` (홈 번들 제외) |

### 8.11 표 (핵심 제약)

## 11. 접근성

| 항목 | 기준 |
| --- | --- |
| 아이콘 전용 버튼 | `title` 필수, 슬라이더 등은 `aria-label` |
| 키보드 | 모달·아코디언·드롭다운은 Radix 기본 포커스 트랩/이동 준수 |
| 포커스 표시 | `--ring` 브랜드 블루, 절대 `outline: none` 단독 사용 금지 |
| 대비 | 본문 텍스트는 `slate-100~300`으로 배경 대비 확보. 10px 캡션에는 중요 정보를 단독 배치하지 않음 |
| 색 의존 | 시설팀 구분은 색 + **라벨(팀명) 병기** |
| 비활성 | `disabled` 상태에 사유를 툴팁으로 제공 |

## 12. 리스킨 가이드

브랜드를 바꿔야 할 때 수정 지점은 **3곳**이다.

1. `tailwind.config.ts` → `colors.slate` / `colors.indigo` 램프
2. `globals.css` → `--primary` · `--ring` (라이트/다크 각각)
3. `tailwind.config.ts` → `boxShadow.glow` / `glow-sm`의 브랜드 hex

**변경하지 말 것**: `constants/facility-teams.ts`의 팀 색 6종과 상태 색 4종 — 데이터 의미가 고정된 색이다.

## 13. 디자인 체크리스트

새 UI를 추가할 때 확인한다.

- [ ] 표 셀에 줄바꿈이 없는가 (`whitespace-nowrap`)
- [ ] 가로 스크롤이 생기지 않는가
- [ ] 아이콘 전용 버튼에 `title`/`aria-label`이 있는가
- [ ] 활성/포커스가 글로우로 표현되는가
- [ ] 로딩·빈 상태·부분 실패 문구가 각각 정의되었는가
- [ ] 결과 토스트가 건수를 숫자로 알리는가
- [ ] 시설팀 색을 임의 색으로 대체하지 않았는가
- [ ] 무거운 UI를 `next/dynamic`으로 지연 로드했는가 (홈 First Load 482 kB 유지)
- [ ] 로그인 필요 기능에 잠금 표시와 사유 툴팁이 있는가
