## 4. 수동 검증 체크리스트 (릴리스 필수)

### 4.1 백업 → 복원 왕복 (TC-B05)

```
□ 현재 데이터 백업 실행 → 5개 시트 엑셀 다운로드 확인
□ markers 시트에 group_key 열 존재 확인
□ 복원 실행 (덮어쓰기 경고 확인)
□ 검증: markers / information / erp_details / battery_markers / battery_specs 행 수 동일
□ 검증: 분리 그룹 구조 동일 (group_key 유지)
□ 검증: 그룹당 대표 1개 유지
□ 검증: DATABASE §7 정합성 쿼리 ①②③ 모두 0행
```

| ID | 케이스 | 기대 |
| --- | --- | --- |
| TC-B02 | 복원 시 `parent_marker_id` | 저장값이 아니라 **유효 키 + `group_role`로 재파생** |
| TC-B03 | `group_key` 열 없는 **구 백업** 복원 | null 폴백 → 번지 그룹으로 안전 복원 |
| TC-B04 | 시트/헤더 불일치 파일 | **복원 중단** + 안내 (부분 반영 없음) |
| TC-B06 | 한글 색상명(오타 `에멜랄드` 포함) | hex로 정규화 |

### 4.2 그룹 분리 → 원복 왕복

```
□ 같은 번지에 5개 이상 국소가 있는 대표 마커 상세 열기
□ 동 라벨 그룹 확인
□ [분리] → 대표 직접 선택 → 확인
□ 새 대표 핀이 겹쳐 생성됨 + 안내 토스트 확인
□ 새 핀을 실위치로 드래그 → 저장 확인
□ 원 그룹 대표가 정상인지 확인 (dangling parent 없음)
□ [번지로 합치기] 실행
□ 대표 1핀으로 복귀 확인
```
