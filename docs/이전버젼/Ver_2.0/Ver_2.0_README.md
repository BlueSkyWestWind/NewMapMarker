# Ver_2.0 문서 세트

- 제품: **MapMarker Pro** (`0004_NewMapMarker`)
- 문서 버전: **Ver_2.0** — 2026-08-01
- 이전 버전: [Ver_1.1](../Ver_1.1/) · [Ver_1.0](../Ver_1.0/)
- 계획서: [Ver_2.0_implementation_plan.md](./Ver_2.0_implementation_plan.md)

> Ver_2.0의 주제는 **셸 개편**이다.
> 최상위 전환 축을 **모드(데이터 도메인)** 에서 **메뉴(기능 영역)** 로 옮기고,
> 그 위에 **대시보드**("오늘 이 국소에서 작업해도 되는가")를 기본 진입 화면으로 신설한다.

> ⚠️ **이 문서 세트는 구현 착수 전에 작성됐다.**
> Ver_1.1 문서가 완료된 구현의 기록이었던 것과 달리, 여기 적힌 컴포넌트·상수·파일은
> 아직 **존재하지 않는 설계**다. 「현재」로 표기된 것만 실제 코드에서 확인한 값이다.
> 구현 중 확정된 값이 설계와 다르면 이 문서를 갱신한다.

## Ver_1.1 → Ver_2.0 요약

| 항목 | Ver_1.1 (현재) | Ver_2.0 (목표) |
| --- | --- | --- |
| 최상위 전환 축 | 모드 4종 (장비·축전지·위치·날씨) | **메뉴 7종** — 모드는 패널 안 세그먼트로 강등 |
| 기본 진입 화면 | 지도 (`mode: equipment`) | **대시보드** |
| 좌측 폭 | 사이드바 340px | 레일 200 + 패널 340 = **540px** |
| 날씨 위치 | 사이드바 「날씨&CCTV」 탭 | **대시보드 전용 화면** |
| CCTV 위치 | 날씨 탭 안 아코디언 | **독립 메뉴** |
| 백업/복원 위치 | 사이드바 footer 아코디언 | **독립 메뉴** (기능은 그대로 이동) |
| 주소/좌표 변환기 | `/gpsmap` 별도 페이지 링크 | 지도 **위치 세그먼트에 통합** (라우트는 유지) |
| 비로그인 화면 | 위치 탭만 잠김 | **메뉴 자체를 숨김** (대시보드·지도·CCTV만 노출) |
| 전역 검색 | 없음 | **상단 검색바 + `Ctrl+K`** |

## 착수 전 확인 사항

1. **`Ver_2.0_implementation_plan.md`가 요구·결정의 단일 소스다.** 이 폴더의 문서는 설계 전개일 뿐,
   범위·완료 기준이 충돌하면 계획서를 따른다.
2. **[COMPONENT §7 불일치 목록](./Ver_2.0_COMPONENT.md#7-계획-대비-코드-불일치-착수-전-결정-필요)** 을 먼저 읽는다 —
   §7.1(백업/복원)은 「이동만」으로 확정돼 해소됐고, **§7.3(메뉴 전환이 필터를 지움)이 남아 있다.**
3. 2단계(기존 사이드바 통째 이식)를 건너뛰지 않는다. 계획서 §6의 근거 참조.
