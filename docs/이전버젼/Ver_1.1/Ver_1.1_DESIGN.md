## 1. 디자인 원칙 (Ver_1.1 추가)

Ver_1.0의 다크 테마·글로우 원칙을 유지하되, 안전 판정 UI에는 다음을 더한다.

| # | 원칙 | 이유 |
| --- | --- | --- |
| D1 | **결론 우선** — 종합 판정을 가장 크게, 가장 위에 | 현장에서 3초 안에 판단해야 한다 |
| D2 | **등급 표기 단일화** — 같은 등급은 어디서나 같은 아이콘·이름·색 | 지도와 사이드바가 다르면 위험도를 오판한다 |
| D3 | **모르는 것은 모른다고 표시** — 결측을 회색 `—`로 | 추정값을 채우면 조용히 틀린다 |
| D4 | **경보 피로 방지** — 상시 발효 특보로 전 국소를 ⛔로 만들지 않는다 | 매일 ⛔면 아무도 안 본다 |
| D5 | **현장 태블릿 기준** — 직사광 대비 고대비, 장갑 착용 조작 | 옥외 작업 환경 |

## 2. 판정 등급 색상 시스템

**단일 소스**: `features/worksite-weather/types/weather.ts`
지도 오버레이(`overlay-content.ts`)와 사이드바가 반드시 이 상수를 참조한다.

| 등급 | 아이콘 | 라벨 | `VERDICT_TONE` |
| --- | --- | --- | --- |
| `safe` | 🟢 | 양호 | `bg-emerald-950/80 border-emerald-800/60 text-emerald-200` |
| `caution` | 🟡 | 주의 | `bg-amber-950/80 border-amber-800/60 text-amber-200` |
| `warning` | 🟠 | 경고 | `bg-orange-950/80 border-orange-800/60 text-orange-200` |
| `danger` | 🔴 | 위험 | `bg-rose-950/80 border-rose-800/60 text-rose-200` |
| `stop` | ⛔ | 중지 | `bg-red-950 border-red-800 text-red-100` |
| `unknown` | — | 판정 불가 | `bg-slate-800 border-slate-700 text-slate-200` |

> ⚠️ **금지**: 컴포넌트 로컬에 등급 맵을 다시 정의하는 것.
> Ver_1.1 검수에서 `caution`이 사이드바 "주의" / 지도 "관심", `warning`이 "경고" / "주의"로
> 갈려 있던 사례가 있었다. 같은 국소가 화면마다 다른 위험도로 보인다.

### 2.1 종합 판정 배너 톤 (`OVERALL_TONE`)

패널 상단 배너는 테두리를 강조한 별도 톤을 쓴다. 등급 의미는 위와 동일.

| 등급 | 클래스 |
| --- | --- |
| `safe` | `border-emerald-600/50 bg-emerald-950/40 text-emerald-200` |
| `caution` | `border-amber-600/50 bg-amber-950/40 text-amber-200` |
| `warning` | `border-orange-600/50 bg-orange-950/40 text-orange-200` |
| `danger` | `border-rose-600/50 bg-rose-950/40 text-rose-200` |
| `stop` | `border-rose-500 bg-rose-950/70 text-rose-100` |

## 3. 기능별 색상 배정

| 영역 | 색 계열 | 근거 |
| --- | --- | --- |
| 날씨 모드 탭·저장 국소 | **sky** (`sky-400`, `sky-950`) | 하늘 = 기상. 기존 3모드(indigo/emerald/emerald)와 구분 |
| 태풍 배너·모달 | **rose** (`rose-300~950`) | 최고 위험. 즉시 눈에 띄어야 함 |
| 위성/레이더 버튼 | sky → indigo 그라데이션 | 관측 데이터 |
| 결측·경고 문구 | `amber-400` | 오류(rose)와 구분되는 "확인 필요" |
| 표·목록 기본 | slate 계열 | 기존 시스템 승계 |

## 4. 레이아웃 — 타임라인 표

프로젝트 필수 규칙: **셀 줄바꿈 금지 · 가로 스크롤 금지 · 세로 스크롤 허용**

Ver_1.1 초안의 7열은 사이드바 폭(340px)에서 줄바꿈을 유발해 **6열로 통합**했다.

| 열 | 내용 | 폭 | 비고 |
| --- | --- | --- | --- |
| 시각 | `15시` | 36px | 경과 슬롯은 `text-slate-600` |
| 기온/체감 | `32 / 36.1` | auto | 한 셀 병합 |
| 습도 | `65%` | auto | |
| 바람 | `서남서 11.2` | auto | **방위+수치 한 셀** — 방위만으론 위험도 판단 불가 |
| 강수 | `60% 1.5mm` | auto | 확률+강수량 한 셀 |
| 판정 | `⛔` | 34px | 아이콘만, `title`에 등급·출처 |

- 전 셀 `whitespace-nowrap` + `tabular-nums`
- `table-fixed`로 열 흔들림 방지
- 행 `title`에 판정 사유 노출

### 5.2 `TyphoonBanner`

| 요소 | 스펙 |
| --- | --- |
| 컨테이너 | `border-rose-500/60 bg-rose-950/60 shadow-md` |
| 아이콘 | 🌀 `animate-spin text-sm` |

### 5.3 `HazardSummaryList`

4종(폭염·강풍·강수·한파) 고정 순서. 해당 없으면 `⚪ + "해당 없음"`.
항목당 `rounded-md bg-slate-900/60 px-2 py-1.5`, 아이콘·라벨·피크값 한 줄 + 권고 문구 한 줄.

### 5.4 지도 정보창 날씨 카드

| 상태 | 표시 |
| --- | --- |
| 조회 중 | `⛅ 현재 시각 날씨 조회 중...` (`animate-pulse`) |
| 성공 | 현재 시각 슬롯 6열 그리드 + 종합 판정 배너 + 발효 특보 |
| 실패 | `기상 정보를 불러오지 못했습니다` (`text-slate-400`) |

클래스: `.overlay-weather-card` (globals.css). 정보 카드와 **분리된 독립 박스**로 상단에 배치.

## 6. 모션

| 대상 | 모션 | 이유 |
| --- | --- | --- |
| 날씨 조회 중 (오버레이) | `animate-pulse` | **로딩 상태 표시** — 유일하게 의미 있는 모션 |
| 위성 버튼 아이콘 | `animate-pulse` | 실시간 데이터 암시 |

### 6.1 상시 반복 모션 금지

**끝나지 않는 애니메이션은 쓰지 않는다.**

태풍 아이콘(🌀)에 `animate-spin`을 걸었다가 전부 제거했다.
사이드바는 작업 중 계속 떠 있는 영역이라, 멈추지 않고 도는 요소가 시야 주변에서 계속
움직이면 정작 읽어야 할 판정 표를 방해한다. 현장에서 "매우 거슬린다"는 피드백을 받았다.

| 원칙 | 내용 |
| --- | --- |
| M1 | 로딩처럼 **끝이 있는 상태**에만 모션을 쓴다 |
| M2 | 상시 노출 영역(사이드바·배너)에 무한 반복 모션 금지 |
| M3 | 판정 결과 자체에는 모션을 넣지 않는다 (가독성 우선) |
| M4 | 주의를 끌어야 하면 **색과 아이콘**으로 한다 — 태풍 배너는 rose 톤 + ⛔ 문구로 충분하다 |

## 7. 상태 표현 규칙

| 상태 | 표현 |
| --- | --- |
| 조회 중 | `기상 정보를 불러오는 중...` `text-slate-400` |
| 오류 | 오류 메시지 `text-rose-400` |
| 결측 경고 | `⚠️ {문구}` `text-amber-400` |
| 고지 문구 | `⚠️ {disclaimer}` `text-slate-500` — **항상 표시** |
| 미선택 | 안내 문구 `text-slate-500` |
| 경과 시간대 | `text-slate-600` (숨기지 않음) |

## 9. 접근성

| 항목 | 처리 |
| --- | --- |
| 색 의존 금지 | 판정을 아이콘(🟢🟡🟠🔴⛔) + 텍스트 라벨로 이중 표기 |
| 터치 영역 | 현장 태블릿·장갑 고려. 주요 버튼 `h-8`(32px) 이상, 목록 항목은 전체 폭 |
| 대비 | 직사광 대비 배경 `-950/80` + 텍스트 `-200` 조합으로 고대비 유지 |
| 장식 아이콘 | `aria-hidden` (예: 태풍 이모지) |
| 툴팁 | `title` 속성으로 판정 사유·출처 제공 |

## 10. 리스킨 가이드 (Ver_1.1 추가분)

색을 바꾸려면 **아래 3곳만** 수정한다.

| 파일 | 상수 |
| --- | --- |
| `worksite-weather/types/weather.ts` | `VERDICT_ICON` · `VERDICT_LABEL` · `VERDICT_TONE` |
| `worksite-weather/components/worksite-weather-panel.tsx` | `OVERALL_TONE` |
| `app/globals.css` | `.overlay-weather-card` |

컴포넌트 내부에 등급 색을 하드코딩하지 않는다.

## 11. 디자인 체크리스트

- [ ] 판정 등급 표기가 지도·사이드바에서 동일한가
- [ ] 타임라인 표가 사이드바 최소 폭에서 줄바꿈·가로스크롤 없이 들어가는가
- [ ] 결측 슬롯이 `—`로 구분되는가 (0이나 빈칸이 아니라)
- [ ] 고지 문구가 화면과 저장 자료 양쪽에 있는가
- [ ] 태풍 미발효 시 배너 DOM이 없는가
- [ ] 판정을 색만으로 구분하지 않는가
- [ ] 경과 시간대가 회색이되 숨겨지지 않는가
