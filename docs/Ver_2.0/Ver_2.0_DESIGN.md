- 제품: **MapMarker Pro** (`0004_NewMapMarker`)

- 작성일: 2026-08-01
- 이전 버전: [Ver_1.1 DESIGN](../Ver_1.1/Ver_1.1_DESIGN.md) — **색·판정 표기·모션 원칙은 그대로 승계**
- 관련 문서: [계획서](./Ver_2.0_implementation_plan.md) · [IA](./Ver_2.0_IA.md) · [COMPONENT](./Ver_2.0_COMPONENT.md)

> 구현 착수 전 설계 문서다. 치수·클래스는 목표값이며, 「현재」 표기만 코드에서 확인한 값이다.

## 1. 디자인 원칙 (Ver_2.0 추가)

Ver_1.1의 D1~D5(결론 우선 · 등급 표기 단일화 · 결측 명시 · 경보 피로 방지 · 현장 태블릿 기준)를
유지하고, 셸 개편에 다음을 더한다.

| # | 원칙 | 이유 |
| --- | --- | --- |
| S1 | **지도가 주인공** — 좌측은 540px 고정, 나머지는 전부 지도 | 목적이 위치 판단이다. 패널이 지도를 잠식하면 본말전도 |
| S2 | **한 화면 = 한 목적** — 읽기(지도)와 쓰기(마커관리)를 섞지 않는다 | 조회 중 실수로 업로드를 누르는 경로를 없앤다 |
| S3 | **없는 것은 보여주지 않는다** — 잠긴 메뉴는 비활성이 아니라 숨김 | 비활성 항목이 늘어서면 쓸 수 없는 제품처럼 보인다 |
| S4 | **되돌릴 수 없는 조작은 결과를 먼저 적는다** | "축전지 41건이 모두 지워집니다" |
| S5 | **폭은 상수 하나** — 치수를 컴포넌트에 적지 않는다 | 현재 340이 세 파일에 흩어져 한 곳만 고치면 어긋난다 |

## 2. 레이아웃 치수

```
┌────────┬──────────────────────────────────────────────────┐
│        │  TopSearchBar                            h-12    │
│ NavRail├──────────────┬───────────────────────────────────┤
│ 200px  │  WorkPanel   │  MapStage                         │
│        │  340px       │  나머지 전부                       │
│        │              │                                   │
│ ─────  │              │        [영역 캡처 패널]            │
│ 계정   │              │              [플로팅 컨트롤]       │
└────────┴──────────────┴───────────────────────────────────┘
   └──────── 540px ────────┘  ← 지도 좌측 오프셋
```

| 영역 | 치수 | 상수 |
| --- | --- | --- |
| `NavRail` | `w-[200px]` · 전체 높이 | `NAV_RAIL_WIDTH_PX` |
| `WorkPanel` | `w-[340px]` · 세로 스크롤 | `WORK_PANEL_WIDTH_PX` |
| `TopSearchBar` | `h-12` · 패널 우측부터 화면 끝까지 | — |
| 좌측 총 점유 | **540px** | 두 상수의 합 |

**단일 소스는 `features/shell/constants.ts`다.** Tailwind 임의값(`w-[340px]`)을 컴포넌트에 직접
적지 않고 인라인 스타일 또는 CSS 변수로 상수를 주입한다. 픽셀 계산이 필요한 곳
(`cctv-video-modal`, `map-region-capture-panel-view`)이 같은 값을 import 해야 하기 때문이다.

## 3. 반응형

3단(레일+패널+지도) 구성이 좁은 화면에서 무너진다. **가로 스크롤은 어떤 폭에서도 금지**다.

| 폭 | 규칙 |
| --- | --- |
| ≥ 1280px | 기본 3단. 전부 펼침 |
| 1024~1279px | 3단 유지. 지도 최소폭 확보를 우선하고 패널 내부 여백을 줄인다 |
| < 1024px | **`WorkPanel` 접힘** — 레일 아이콘 클릭 시 지도 위에 오버레이로 띄운다 |
| < 768px | 레일도 아이콘 전용(라벨 숨김)으로 축소 |

- 패널 접힘 상태는 기존 `isSidebarOpen`을 재사용한다(새 플래그를 만들지 않는다).
- 접힘 시 지도의 좌측 오프셋이 달라진다 — **뷰포트 고정 요소**(`cctv-video-modal.tsx:114`의
  `fixed inset-0` + `paddingLeft`)가 같은 상수 계산을 타야 한다.

### 3.1 영역 캡처 패널

**지도 컨테이너 안에 있으므로 오프셋을 더하지 않는다.** `map-region-capture-panel-view.tsx:95`의
`absolute left-4`는 `kakao-map-canvas.tsx:957`의 `relative` 컨테이너 기준이라 레일·패널이 늘어도
겹치지 않는다. 오프셋을 더하면 오히려 지도 안쪽으로 밀린다.

실제 문제는 폭이다. 좌측 점유가 540px가 되면 1024px 화면의 지도 영역은 **484px**인데
이 패널이 340px를 차지한다.

| 폭 | 캡처 패널 |
| --- | --- |
| ≥ 1280px | 현행 `w-[340px]` 유지 |
| < 1024px | 폭 축소 또는 하단 배치로 전환 — 지도가 최소 절반은 보여야 캡처 범위를 확인할 수 있다 |

| 비활성 | `text-slate-400 hover:text-slate-200` |

### 4.2 `WorkPanel`

| 요소 | 스펙 |
| --- | --- |
| 컨테이너 | `flex h-full w-[340px] shrink-0 flex-col border-r border-slate-800 bg-slate-950/95` |
| 헤더 | 메뉴 라벨 + 건수 배지. `border-b border-slate-800 px-4 py-3` |
| 세그먼트 | 헤더 아래 고정. `ModeTabs`를 세그먼트 컨트롤로 축소해 재사용 |
| 본문 | `min-h-0 flex-1 overflow-y-auto p-4` — **세로 스크롤만** |
| 카드 | 섹션당 `rounded-lg border border-slate-800 bg-slate-900/60 p-3` |

> **`backdrop-blur`를 패널 컨테이너에 걸지 않는다.** `backdrop-filter`는 컨테이닝 블록을 만들어
> `position: fixed` 자식을 패널 안에 가둔다. 모달은 계속 `body` 포털을 쓰지만, 새 패널에
> blur를 추가하면 내부 팝오버·드롭다운이 잘린다. (현재 사이드바에 `backdrop-blur`가 있다 —
> 이식할 때 함께 옮기지 않는다.)

## 5. 색 배정

Ver_1.1의 기능별 색 배정을 유지하고, 메뉴에는 **새 색 계열을 만들지 않는다.**

| 영역 | 색 | 근거 |
| --- | --- | --- |
| 활성 메뉴 · 활성 세그먼트 | **indigo** (`indigo-600`) | 현재 활성 탭과 동일. 새 색을 만들면 학습 비용만 는다 |
| 대시보드 · 기상 | **sky** | Ver_1.1 날씨 계열 승계 |
| CCTV | **teal** (`teal-400`) | 현재 CCTV 아코디언 아이콘 색 승계 |
| 백업/복원 | **emerald** | 현재 아이콘 색 승계 |
| 삭제·중지 | **rose / red** | 파괴적 조작 · 최고 위험 |
| 잠김·준비 중 | **slate + opacity** | 색으로 유혹하지 않는다 |
| 판정 등급 | `VERDICT_TONE` **그대로** | 재정의 금지 — §7 |

## 6. 대시보드 표시 규칙

### 6.1 목록 행 (`WorksiteRow`)

| 요소 | 스펙 |
| --- | --- |
| 컨테이너 | `rounded-md border border-slate-800 bg-slate-900/60 px-2 py-1.5` · 선택 시 `border-sky-500/50 bg-sky-950/60` |
| 1행 | 판정 아이콘 + 국소명(`font-semibold`) + 판정 라벨 배지(우측) |
| 2행 | 주소 · 작업유형 `text-[11px] text-slate-400` · `truncate` |
| 3행 | 위험요약 요점 `text-[11px]` |
| 4행 | 권장 시간대 `text-[11px] text-emerald-300` — 없으면 「권장 시간대 없음」 |
| 조회 중 | 스켈레톤 또는 `조회 중...` `text-slate-500` |
| 실패 | `⚠️ 조회 실패` `text-amber-400` + `[다시 시도]` 버튼 |

행 전체가 클릭 영역이다(현장 태블릿·장갑 기준). 높이 최소 44px 확보.

### 6.2 빈 상태

작업대상 0건은 **오류가 아니라 정상 상태**다.

```
🔖 저장된 작업 국소가 없습니다
지도에서 국소를 검색해 「오늘의 작업 국소로 저장」을 누르면
여기에 당일 기상 판정이 표시됩니다.
[지도로 이동]
```

### 6.3 목록 ↔ 지도 연동

| 조작 | 반응 |
| --- | --- |
| 목록 행 클릭 | 지도가 해당 국소로 이동 + 마커 강조 |
| 지도 마커 클릭 | 목록에서 해당 행 선택·스크롤 |
| 목록 건수 | 지도 마커 건수와 **항상 일치** (같은 출처를 쓴다) |

### 6.4 상세 영역

`HazardSummaryList` · `WeatherTimelineTable` · `TyphoonBanner`를 **그대로** 쓴다.
타임라인 표는 6열 · 11행 · `table-fixed` · 전 셀 `whitespace-nowrap` — Ver_1.1 §4 규칙 유지.
패널 폭이 340px로 동일하므로 열 구성을 다시 계산할 필요가 없다.

## 7. 판정 표기 (단일 소스 — 재정의 금지)

**대시보드는 자체 등급 맵을 만들지 않는다.**

| 상수 | 위치 |
| --- | --- |
| `VERDICT_ICON` · `VERDICT_LABEL` · `VERDICT_TONE` · `VERDICT_RANK` | `worksite-weather/types/weather.ts` |
| `OVERALL_TONE` (배너 톤) | `worksite-weather/types/weather.ts` — 2026-08-01 패널에서 **승격 완료** |

> Ver_1.1 검수에서 `caution`이 사이드바 "주의" / 지도 "관심"으로 갈려 있던 사례가 있었다.
> 같은 국소가 화면마다 다른 위험도로 보인다. 대시보드가 세 번째 표기 지점이 되므로
> **다섯 상수 모두 import만 하고 재정의하지 않는다.**

## 10. 모션 (Ver_1.1 M1~M4 승계)

**끝나지 않는 애니메이션은 쓰지 않는다.** 현장에서 "매우 거슬린다"는 피드백으로 제거한 이력이 있다.

| 원칙 | 내용 |
| --- | --- |
| M1 | 로딩처럼 **끝이 있는 상태**에만 모션을 쓴다 |
| M2 | 상시 노출 영역(레일·패널·배너)에 무한 반복 모션 금지 |
| M3 | 판정 결과 자체에는 모션을 넣지 않는다 |
| M4 | 주의를 끌어야 하면 **색과 아이콘**으로 한다 |

Ver_2.0 추가: **메뉴 전환에 슬라이드·페이드 전환을 넣지 않는다.** 패널 내용이 즉시 바뀌어야
연속 조작이 끊기지 않는다. 패널 접힘/펼침만 `transition-[width]` 150ms를 허용한다.

## 11. 접근성

| 항목 | 처리 |
| --- | --- |
| 키보드 네비게이션 | 레일 메뉴는 `Tab` 순회 + `Enter`/`Space` 활성화 |
| 전역 검색 | `Ctrl+K` 포커스 · `Esc` 닫기 · `↑↓` 이동 · `Enter` 선택 |
| 포커스 표시 | 레일·세그먼트·검색 결과에 가시적 포커스 링 (`ring-2 ring-indigo-500`) |
| 현재 위치 | 활성 메뉴에 `aria-current="page"` |
| 잠김 상태 | `disabled` + `title`. 색만으로 구분하지 않는다 |
| 터치 영역 | 메뉴 `h-10`(40px), 대시보드 행 최소 44px |
| 색 의존 금지 | 판정은 아이콘(🟢🟡🟠🔴⛔) + 텍스트 라벨 이중 표기 |
| 대비 | 직사광 대비 `-950/80` 배경 + `-200` 텍스트 |
