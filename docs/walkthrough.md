## [2026-06-06] 상세 장비 테이블 열(Column) 복사 및 개별 셀 더블클릭 단건 복사 기능 개선 작업 결과

### 1. 개요 및 목적
- 테이블 뷰에서 텍스트를 드래그할 때 불필요한 행과 주변 텍스트가 같이 선택되어 엑셀 편집에 방해되는 문제를 예방하고, 특정 열(예: 통합시설코드 열 전체)만 세로 방향으로 복사하거나 개별 필드의 텍스트만 원클릭으로 쉽게 복사할 수 있는 프리미엄 복사 기능을 도입하여 사용성을 획기적으로 개선하였습니다.

### 2. 변경된 내용
- **`index.html` 내 열 복사 지시자 제공**
  - 상세 정보 테이블의 헤더(`th`) 우측에 세련된 복사 아이콘(`<i class="fa-regular fa-copy col-copy-btn">`)과 툴팁을 추가하여 열 전체 복사가 가능함을 명시했습니다.
- **`style.css` 내 셀 드래그 포인터 교체**
  - 테이블 셀(`td`) 영역에 마우스를 호버하면 선택을 더 쉽게 하도록 마우스 커서 모양을 십자선 셀 포인터(`cursor: cell;`)로 변경해 편의성을 제공합니다.
- **`app.js` 내 복사 제어 로직**
  - **열 단위 복사 (`handleCopyColumn`)**: 헤더의 복사 아이콘을 누르면 해당 컬럼의 모든 값만 세로로 솎아내어 개행 문자(`\n`)로 조립 후 클립보드에 적재하여, 엑셀의 특정 열에 그대로 세로 붙여넣기가 가능하도록 연결했습니다.
  - **셀 단위 복사 (더블클릭) 이벤트**: 텍스트 드래그에 간섭하지 않으면서 셀의 전체 값을 완벽히 가져갈 수 있도록, 셀을 **더블클릭(dblclick)** 하면 셀 내부 텍스트 전체를 즉시 클립보드에 복사하고 전용 토스트 메시지를 띄우도록 바인딩했습니다.

### 3. 검증 결과
- **열 전체 복사**: 테이블의 `통합시설코드` 헤더 옆 복사 단추 클릭 시 `202634277\n202634276\n202634274...` 형태로 6건의 코드가 세로 복사되어 엑셀 시트에 단번에 붙여넣어짐을 검증했습니다.
- **셀 단위 복사**: 드래그 방해 없이 셀을 더블클릭할 때 셀 원본 값만 오차 없이 복사되며 토스트 알림이 정상 표출됨을 확인했습니다.

## [2026-06-06] 연관 장비 다중 행(Excel 가로 표 목록) 렌더링 및 복사 기능 개선 작업 결과

### 1. 개요 및 목적
- 한 마커(국소) 내에 설치된 장비 정보가 여러 개 존재할 수 있으므로, 단일 상세 조회 방식에서 벗어나 엑셀 시트와 동일한 가로형의 다중 행 목록(`시설연도 | 프로젝트코드 | 통합시설코드 | 사업구분 | 국소명-최종 | 장비타입 | 시설일 | 개통일`)으로 렌더링하고, 이 다중 행 데이터를 클립보드에 한 번에 복사할 수 있는 기능을 완성하여 사용자 엑셀 정리 작업의 속도와 정확성을 높였습니다.

### 2. 변경된 내용
- **`index.html` 내 가로형 여러 행 테이블 설계**
  - 모달의 상세 장비 영역에 가로형 엑셀 표와 동일한 스크롤 가능한 구조의 `thead` 컬럼 구성을 신설하고, 동적 장비 행이 대입될 `tbody#detailed-info-table-body` 영역을 지정했습니다.
- **`style.css` 내 테이블 너비 유연성 및 셀 줄바꿈 방지**
  - 고정 가로 너비(50%) 제한을 제거하고 데이터 길이에 맞춰 동적으로 셀의 폭이 조정되도록 개선했으며, 셀 내 텍스트 줄바꿈을 방지하는 `white-space: nowrap` 속성을 추가하였습니다.
- **`app.js` 내 국소 기준 장비 다중 조회 및 다중 클립보드 복사**
  - **다중 레코드 연동 (`fetchAndBindDetailedInfo`)**: Supabase `information` 테이블에서 현재 마커의 이름을 포함(`ILIKE`)하는 모든 장비 목록을 한 번에 조회하여 테이블 body 내에 `tr` 행들로 누적 생성합니다. (로컬 캐시 혹은 pending 마커의 경우 기본 1행 캐시 출력 지원)
  - **다중 행 TSV 복사 개편 (`handleCopyDetailedTable`)**: 렌더링된 상세 정보 테이블 내 모든 행을 순회하여 헤더 정보와 실제 값을 탭 구분 TSV 형식의 멀티라인 데이터로 조립 후 클립보드에 저장하도록 개선했습니다.

### 3. 검증 결과
- 특정 마커 상세 정보 클릭 시 이미지에 첨부된 형태의 엑셀 데이터 표 레이아웃이 가로 스크롤과 함께 잘림 없이 출력됨을 확인했습니다.
- "표 전체 복사" 수행 시 총 행수에 관한 복사 완료 토스트가 정상 출력되며, Excel 시트에 복사-붙여넣기 시 여러 개의 장비 상세 행들이 원본 데이터 그대로 완벽하게 행/열 매핑되어 붙여넣어짐을 검증하였습니다.

## [2026-06-06] Supabase 'information' 테이블 연동 및 엑셀 상세 필드 업로드 작업 결과

### 1. 개요 및 목적
- Supabase에 새로 생성된 `information` 상세 데이터베이스 테이블을 엑셀 업로드 시 연동하고, 지도상의 마커 클릭 시 해당 정보를 모달 창 하단에 로드 및 편집할 수 있도록 CRUD 전반을 연결 및 완성하였습니다.

### 2. 변경된 내용
- **`app.js` 내 Supabase 및 UI 연동**
  - **초기 로드 데이터 매핑 보완 (`init`)**: Supabase `markers` 테이블에서 데이터를 로드할 때 `facilityCode: row.facility_code` 속성을 누락 없이 `markersData` 객체 메모리에 바인딩하도록 추가하였습니다.
  - **상세 정보 저장 및 중복 방지 (`handleSaveMarker`)**:
    - 모달 창 폼 요소들로부터 상세 속성 값(`facilityCode`, `projectCode`, `facilityYear`, `businessType`, `eqClass`, `eqType`, `installDate`, `openDate`)을 정상 수집합니다.
    - 데이터 무결성 유지를 위해, 입력받은 `facilityCode`가 이미 로컬 메모리 `markersData`에 존재하는 타 마커의 코드와 중복되는지 검증하고, 중복이 있을 시 저장을 조기 차단하여 토스트 경고를 띄웁니다.
    - 신규 마커 등록 및 기존 마커 수정 시 `markers` 테이블에는 `facility_code` 외래 식별자를 저장하며, `information` 테이블에는 상세 레코드를 `facility_code`를 PK로 지정하여 `upsert` 갱신 처리합니다.

### 3. 검증 결과

## [2026-06-06] 마커 상세 및 편집 모드 분리 작업 결과

### 1. 개요 및 목적

### 2. 변경된 내용
- **`app.js` 내 상세/편집 분리 대응**
  - **오버레이 버튼 구성 변경 (`createOverlayContent`)**: [상세] 버튼과 [편집] 버튼을 모두 생성하여 하단 액션바에 추가하고, 클릭 이벤트가 지도 또는 마커로 전달되어 원치 않는 이동이 발생하지 않도록 `e.stopPropagation()` 처리를 추가하였습니다.
  - **폼 읽기 전용 토글 헬퍼 (`toggleModalReadOnly`)**: 장소 이름, 메모, 태그 등의 입력 필드를 대상으로 `readonly` 속성과 `input-readonly` CSS 클래스를 동적으로 제어합니다. 위도와 경도는 원래 설계대로 항상 읽기 전용 상태를 유지합니다.
  - **상세 모달 모드 (`openDetailMarkerModal`)**: 모달 제목을 '마커 상세 정보'로 변경하고 모든 입력 필드를 읽기 전용 상태로 잠급니다. [저장] 및 [삭제] 버튼을 감추고 우측 하단 취소 버튼의 명칭을 '닫기'로 변환합니다.
  - **편집 모달 모드 (`openEditMarkerModal`)**: 모든 입력 필드를 쓰기 가능 상태로 활성화하고, [저장] 버튼을 상시 노출하며 `isPending = true`가 아닌 영구 저장 마커인 경우에만 [삭제] 버튼을 노출합니다.
  - **대기 마커 편집 예외 처리 (`handleSaveMarker`)**: 아직 DB에 저장되지 않은 대기 마커(`isPending = true`)를 수정하여 저장하는 경우, Supabase API를 타지 않고 로컬 메모리상에서만 데이터가 갱신되도록 하였습니다.

### 3. 검증 결과
- **상세 조회**: 오버레이 정보창의 **[상세]** 클릭 시 폼이 비활성화되고 입력이나 수정이 불가능하며 [저장]/[삭제] 버튼이 숨겨지고 오직 [닫기] 버튼만 하단에 렌더링됨을 검증했습니다.
- **정보 편집**: 오버레이 정보창의 **[편집]** 클릭 시 폼이 정상 활성화되고 [저장] 및 [취소] 버튼이 정상 동작하며 수정 정보가 로컬 저장소 및 Supabase에 알맞게 반영됨을 확인했습니다.
